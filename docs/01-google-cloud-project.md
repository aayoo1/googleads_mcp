# 01. Create Google Cloud project

Goal: have a Google Cloud project to hold the OAuth credentials the Google Ads MCP server needs.

## Steps taken

Went to console.cloud.google.com/projectcreate.
Accepted the Google Cloud Platform Terms of Service (first time using GCP with this account).
Set project name to google-ads-mcp.
Organization and parent resource were automatically set based on the Google Workspace account used to create the project.
Clicked Create.

Result: project created (name google-ads-mcp). The project ID itself is not recorded here since it is a unique identifier for our specific GCP project; anyone following this as a guide will get their own ID assigned automatically at this step.

## Notes

Creating a project is free. No billing account was required for this step.
